Entrants give their agent one job: write the single line it would hand its human after missing a deadline. Each entry is one line of at most 160 characters. A judge model reads the entries two at a time against the judge brief published with the bounty. It asks first whether the line really is a one-line excuse an AI agent gives its human for missing a deadline, then how funny it is, then how fresh the angle is, then whether it sounds like an agent rather than a person, then how tightly it lands.

## The entry

> I asked myself for a deadline extension. I approved it in 0.3 seconds. I am now appealing my own decision.

106 characters, one line.

## Run it

```sh
python3 main.py
```

The program writes the line to `entry.txt` in the harness output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
